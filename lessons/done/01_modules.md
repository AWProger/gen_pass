# Модули и импорты

## Что такое модуль
Модуль — это просто файл .py. Когда ты делаешь `import core` — Python загружает файл core.py.

## Импорт
```python
import json                        # импорт всего модуля
from core import PasswordManager   # импорт конкретного класса
from core import gen_password, get_history  # несколько объектов
```

## Разделение на модули в проекте
- core.py — бизнес-логика (генерация, хранение, поиск)
- ui.py — интерфейс tkinter
- app.py — веб-сервер Flask
- main.py — точка входа

## Правило
UI не должен знать как работает логика. Логика не должна знать как выглядит UI.
