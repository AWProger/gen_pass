# История изменений

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
версии — по [Semantic Versioning](https://semver.org/lang/ru/).

## [2.0.0] — 2026-10-02

Первая публичная версия. До неё шифрование не работало между сессиями.

### Исправлено

- **Ключ шифрования больше не пересоздаётся при каждом запуске.** Раньше
  `Fernet.generate_key()` вызывался в конструкторе, поэтому сохранённый файл
  нельзя было открыть после перезапуска — `InvalidToken`. Теперь ключ выводится
  из мастер-пароля через scrypt, соль хранится рядом с хранилищем.
- Изменение или обрезка файла хранилища обнаруживается: данные снабжены MAC и
  проверяются за постоянное время.
- Запись атомарна: файл пишется во временный и подменяется, падение посреди
  сохранения больше не портит хранилище.
- `__pycache__` больше не попадает в репозиторий.
- Правило `*.json` в `.gitignore` заменено на точечное: оно блокировало любые
  легитимные json-файлы.

### Убрано

- **Веб-версия на Flask.** Отдавала пароли по HTTP без авторизации и с
  `debug=True`, что открывало отладочную консоль Werkzeug. Убраны вместе с ней
  XSS в клиентском JavaScript и зависимость от Flask.

### Добавлено

- Замер стойкости в битах энтропии вместо «слабый/средний/сильный» по длине.
- Набор символов по умолчанию не содержит кавычек, обратного слэша и бэктика —
  их отклоняет значительная часть сайтов. Полный набор включается галочкой.
- Длина 8–256, опциональное исключение похожих символов (I l 1 O 0).
- Подтверждения на все необратимые действия: очистка истории, удаление записи,
  удаление файла хранилища.
- Генерация больше не сохраняет пароль автоматически — сохранение отдельным
  действием.
- Мастер-пароль в скрытом поле.
- Буфер обмена очищается через 30 секунд после копирования.
- Предупреждение при экспорте без шифрования.
- Атомарная запись хранилища.

### Техническое

- Зависимостей нет: `secrets`, `hashlib`, `tkinter` из стандартной библиотеки.
  `cryptography`/Fernet заменён на `scrypt` и `blake2b`.
- 49 тестов, проходят на Python 3.10–3.12.
- Сборка PyInstaller переведена в `onefile`.
- README по-русски, лицензия MIT, `pyproject.toml`, CI.

### Известные ограничения

- Забытый мастер-пароль восстановить нельзя — программа его нигде не хранит.
- Файлы `.pwdb` из версии до 2.0.0 не восстанавливаются: прежняя обработка
  ключа делала их нечитаемыми после перезапуска.
- Первый запуск `.exe` медленнее: архив распаковывается во временную папку.
